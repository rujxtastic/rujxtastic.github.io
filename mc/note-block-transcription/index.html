About this tool

  

    Note Block Transcriber is a fully client-side web app that converts
    uploaded audio into Minecraft note block events. Nothing leaves your browser — all
    decoding, FFT analysis, spectral matching, and file export happen locally using the
    Web Audio API.
  

  

    Built by Rujx.
    More projects, source code, and contact info at
    rujxtastic.github.io.
  

  

    Sound bank samples are read from user-supplied .ogg files, or synthesised
    with Web Audio nodes when none are provided. Exports produce a standard
    .nbs file for Note Block Studio, a .mcfunction for datapacks,
    or a rendered .wav / .mp3 of the transcription.
